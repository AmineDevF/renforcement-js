02 · VARIABLES

const prenom = "Yassine";   // ne change pas

03 · CONDITIONS

if / else

const note = 14;

if (note >= 16) {
  console.log("Très bien");
} else if (note >= 10) {
  console.log("Validé");
} else {
  console.log("À revoir");
}

Ternaire = if/else en 1 ligne

const msg = note >= 10
  ? "Validé"
  : "À revoir";

04 · FONCTIONS

Une fonction = une recette

function direBonjour(prenom) {   // paramètre
  return `Bonjour ${prenom} !`;   // résultat
}

const msg = direBonjour("Sara");  // appel + argument
console.log(msg);  // "Bonjour Sara !"
1. définir 2. appeler 3. return = renvoie et s'arrête

04 · FONCTIONS

Fonction fléchée =>

// classique
function carre(n) {
  return n * n;
}
// fléchée
const carre = (n) => {
  return n * n;
};

// version courte
const carre = n => n * n;

Même résultat. On verra la fléchée partout avec map / filter (jour 4).

05 · DOM

Le DOM = la page vue par JS

document
 └ html
    └ body
       ├ h1#titre
       ├ p.info
       └ button#btn
// 1 élément (le premier)
const titre = document.querySelector("#titre");
const info  = document.querySelector(".info");

// plusieurs éléments
const items = document.querySelectorAll("li");

Même syntaxe que le CSS : #id · .classe · balise

05 · DOM

Modifier un élément

titre.textContent = "Nouveau titre";   // texte
titre.innerHTML = "<b>Gras</b>";       // HTML

titre.classList.add("text-red-500");   // classe +
titre.classList.remove("hidden");      // classe −
titre.classList.toggle("hidden");      // on / off

input.value                            // contenu d'un input

Avec Tailwind, on change le style en ajoutant / retirant des classes.
