01 · TABLEAUX

Pourquoi un tableau ?

❌ Une variable par valeur

const fruit1 = "Pomme";
const fruit2 = "Banane";
const fruit3 = "Kiwi";
// et s'il y en a 100 ?

✅ Une liste

const fruits = ["Pomme", "Banane", "Kiwi"];

Un tableau = une liste ordonnée de valeurs.

01 · TABLEAUX

Lire : index & length

"Pomme"

0

"Banane"

1

"Kiwi"

2

fruits[0]                  // "Pomme"
fruits.length              // 3
fruits[fruits.length - 1]  // "Kiwi" (le dernier)

⚠️ On compte à partir de 0.

01 · TABLEAUX

Ajouter & retirer

const fruits = ["Pomme", "Banane"];

fruits.push("Kiwi");    // ajoute à la fin
// ["Pomme", "Banane", "Kiwi"]

fruits.pop();           // retire le dernier
// ["Pomme", "Banane"]

fruits[0] = "Fraise";   // remplace
// ["Fraise", "Banane"]

const sur un tableau : on peut changer son contenu, pas le remplacer.

01 · TABLEAUX

includes : est-ce qu'il contient ?

const fruits = ["Pomme", "Banane", "Kiwi"];

fruits.includes("Kiwi");    // true
fruits.includes("Mangue");  // false

if (!fruits.includes("Mangue")) {
  fruits.push("Mangue");    // pas de doublon
}

Renvoie toujours un boolean. Parfait dans un if.

01 · TABLEAUX

join : tableau → texte

const fruits = ["Pomme", "Banane", "Kiwi"];

fruits.join(", ");   // "Pomme, Banane, Kiwi"
fruits.join(" - ");  // "Pomme - Banane - Kiwi"
fruits.join("");     // "PommeBananeKiwi"

On choisit le séparateur. join("") nous servira pour le HTML.

01 · TABLEAUX

Parcourir avec for

const fruits = ["Pomme", "Banane", "Kiwi"];

for (let i = 0; i < fruits.length; i++) {
  console.log(i, fruits[i]);
}
// 0 "Pomme"
// 1 "Banane"
// 2 "Kiwi"
départ i = 0 tant que i < length puis i++

02 · OBJETS

Un objet = une fiche

const eleve = {
  nom: "Sara",
  note: 15,
  present: true
};
eleve.nom        // "Sara"
eleve.note = 16; // modifier
eleve.ville = "Casa"; // ajouter
tableau [ ] → une liste objet { } → une fiche avec des clés

02 · OBJETS

Tableau d'objets = une vraie base de données

const eleves = [
  { nom: "Sara", note: 15 },
  { nom: "Omar", note: 8 },
  { nom: "Hiba", note: 12 }
];

eleves[1].nom      // "Omar"
eleves.length      // 3

Lire : [index] pour la ligne, puis .clé pour la case.

02 · OBJETS

Spread ... = déplier

Tableaux

const a = [1, 2];
const b = [3, 4];

const copie = [...a];      // [1, 2]
const tout = [...a, ...b]; // [1, 2, 3, 4]
const plus = [...a, 99];   // [1, 2, 99]

Objets

const sara = { nom: "Sara", note: 15 };

const saraBis = { ...sara, note: 18 };
// { nom: "Sara", note: 18 }

Crée une copie : l'original ne bouge pas.

03 · ORDRE SUPÉRIEUR

Une fonction… qu'on donne à une fonction

const direBonjour = (nom) => console.log(`Bonjour ${nom}`);

["Sara", "Omar"].forEach(direBonjour);

// ou directement :
["Sara", "Omar"].forEach((nom) => console.log(`Bonjour ${nom}`));

La méthode fait la boucle. Toi, tu dis juste quoi faire avec chaque élément.

03 · ORDRE SUPÉRIEUR

forEach → faire une action

// avec for
for (let i = 0; i < notes.length; i++) {
  console.log(notes[i]);
}
// avec forEach
notes.forEach((note) => {
  console.log(note);
});

Ne renvoie rien. Sert à afficher, ajouter dans la page…

03 · ORDRE SUPÉRIEUR

map → transformer chaque élément

🍎 🍌 🥝— map →🧃 🧃 🧃 
const notes = [10, 15, 8];
const doubles = notes.map((n) => n * 2);   // [20, 30, 16]

const noms = eleves.map((e) => e.nom);     // ["Sara", "Omar", "Hiba"]

Nouveau tableau, même longueur.

03 · ORDRE SUPÉRIEUR

filter → garder certains

🍎 🍌 🍎 🥝— filter 🍎 →🍎 🍎 
const notes = [10, 15, 8];
const bonnes = notes.filter((n) => n >= 10);        // [10, 15]

const recus = eleves.filter((e) => e.note >= 10);   // Sara, Hiba

Garde ceux où la condition est true. Nouveau tableau, souvent plus court.

03 · ORDRE SUPÉRIEUR

find → trouver le premier

const omar = eleves.find((e) => e.nom === "Omar");
// { nom: "Omar", note: 8 }

const inconnu = eleves.find((e) => e.nom === "Zak");
// undefined
filter → un tableau find → un seul élément (ou undefined)

03 · ORDRE SUPÉRIEUR

reduce → tout résumer en une valeur

🍎 🍌 🥝— reduce →🥗 
const notes = [10, 15, 8];
const total = notes.reduce((somme, n) => somme + n, 0);
// 33
départ

03 · ORDRE SUPÉRIEUR

Les enchaîner

// Les noms des élèves reçus, en une phrase
const phrase = eleves
  .filter((e) => e.note >= 10)   // 1. garder
  .map((e) => e.nom)             // 2. transformer
  .join(", ");                   // 3. coller

// "Sara, Hiba"

Une étape par ligne = code lisible.

BONUS · DANS LA PAGE

map + join("") = du HTML

const liste = document.querySelector("#liste");

liste.innerHTML = eleves
  .map((e) => `<li>${e.nom} : ${e.note}/20</li>`)
  .join("");

Sans join(""), des virgules apparaissent dans la page.
