Tout ce qu'on a vu ce matin, sur une seule liste de sourates.

📁 Fichier de départ : starter.html · 📽 Revoir les slides

RÉFÉRENCES

Tableaux

tab[0]  tab.length
tab.push(x)
tab.includes(x)   // true / false
tab.join(", ")    // → texte
for (let i = 0; i < tab.length; i++) {}

Objets & spread

obj.cle         // lire
obj.cle = 5;    // modifier
[...a, ...b]    // fusionner
[...a]          // copier
{ ...obj, cle: 5 } // copie modifiée

Ordre supérieur

tab.forEach((x) => ...)  // action
tab.map((x) => ...)      // transformer
tab.filter((x) => ...)   // garder
tab.find((x) => ...)     // un seul
tab.reduce((s, x) => s + x, 0)
