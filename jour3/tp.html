✅ Ma to-do connectée

Lire, ajouter, cocher et supprimer des tâches sur une vraie API : async/await + Axios.

📁 Fichier de départ : starter.html · 📽 Revoir les slides · 🌐 API : jsonplaceholder.typicode.com

RÉFÉRENCES

async / await

async function f() {
  await attendre(1000);
  const x = await autreAsync();
}
f();  // ne pas oublier !

Axios · 4 verbes

await axios.get(url)
await axios.get(url, { params: { userId: 1 } })
await axios.post(url, objet)     // 201
await axios.put(`${url}/${id}`, objet)
await axios.delete(`${url}/${id}`)
reponse.data    reponse.status

try / catch

try {
  const r = await axios.get(url);
} catch (erreur) {
  erreur.response?.status // 404…
  message.textContent = "Oups";
}
⚠️ JSONPlaceholder est une fausse API : POST, PUT et DELETE répondent « OK » mais rien n'est enregistré. Donc après chaque réponse, c'est à toi de mettre à jour ton tableau taches, puis d'appeler afficher().

PARTIE B · DANS LA PAGE

  1. 9

    Charger GET · try/catch

    async function charger() : affiche ⏳ Chargement… dans #message, récupère les tâches de l'utilisateur 1, les range dans taches, vide le message et appelle afficher(). En cas d'erreur : ❌ Impossible de charger les tâches. Bonus : mets aussi le nom de l'utilisateur dans #nomUtilisateur.

  2. 10

    Afficher map + join("") · filter

    function afficher() remplit #liste avec le modèle du starter (✅/⬜ et texte barré si terminée), puis #nb et #finies.

  3. 11

    Ajouter submit · POST

    Au submit : refuser un titre vide, envoyer la tâche en POST, puis l'ajouter en haut de taches avec unshift, vider le champ, afficher().
    💡 L'API renvoie toujours id: 201. Pour avoir des id différents : taches.unshift({ ...reponse.data, id: Date.now() }).

  4. 12

    Cocher find · ...spread · PUT

    Dans afficher(), ajoute un addEventListener sur chaque .cocher. Au clic : find la tâche (Number(bouton.dataset.id)), envoie { ...tache, completed: !tache.completed } en PUT, remplace la tâche dans taches (avec map), afficher().
    💡 Une tâche que tu as ajoutée n'existe pas sur le serveur : PUT renvoie une erreur 500. C'est normal ! Ton catch doit afficher un message.

  5. 13

    Supprimer DELETE · filter

    Même principe sur .supprimer : DELETE, puis taches = taches.filter(...), afficher().
