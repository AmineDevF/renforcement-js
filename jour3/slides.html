01 · API

L'API du jour : JSONPlaceholder

https://jsonplaceholder.typicode.com

/todos → 200 tâches

/todos/5 → la tâche n°5

/todos?userId=1 → ses 20 tâches

/users/1 → un utilisateur

🆓 Gratuite, sans clé, sans inscription

✅ Accepte GET, POST, PUT, DELETE

⚠️ C'est une fausse API : elle répond « OK » mais n'enregistre rien.

👉 Colle /todos/1 dans ton navigateur : tu vois le JSON !

02 · ASYNC / AWAIT

Le problème : le serveur prend du temps

🧾

Je commande au fast-food

= j'envoie la requête

🎟️

On me donne un ticket

= une Promise (promesse)

🍔

J'attends mon numéro

= await

Une Promise, c'est « le résultat arrivera plus tard ».

02 · ASYNC / AWAIT

Sans await, on a… le ticket

❌ Sans await

const reponse = axios.get(url);
console.log(reponse);
// Promise {<pending>}
// 😕 le ticket, pas le burger

✅ Avec await

const reponse = await axios.get(url);
console.log(reponse.data);
// { id: 1, title: "..." }
// 🍔 les vraies données

await = « attends la réponse avant de passer à la ligne suivante ».

02 · ASYNC / AWAIT

La recette en 3 étapes

  1. 1 async devant la fonction
  2. 2 await devant ce qui prend du temps
  3. 3 on appelle la fonction
async function charger() {     // 1
  const reponse = await axios.get(url); // 2
  console.log(reponse.data);
}

charger();                     // 3

⚠️ await ne marche que dans une fonction async.

02 · ASYNC / AWAIT · EXEMPLE 1

Attendre 2 secondes

function attendre(ms) {
  return new Promise((ok) => setTimeout(ok, ms));
}

async function cafe() {
  console.log("1. Je commande un café ☕");
  await attendre(2000);
  console.log("2. Café prêt ! 😋");
}

cafe();

💡 attendre est donnée dans le starter : pas besoin de savoir l'écrire, juste de l'utiliser avec await.

02 · ASYNC / AWAIT · EXEMPLE 2

Plusieurs await : chacun son tour

async function petitDej() {
  console.log("☕ Je fais le café...");
  await attendre(1000);
  console.log("🍞 Je grille le pain...");
  await attendre(1000);
  console.log("✅ Bon appétit !");
}

petitDej();
console.log("👀 Pendant ce temps, le reste continue");

🤔 Pourquoi « 👀 » s'affiche en 2e ? La fonction attend, pas le reste de la page.

02 · ASYNC / AWAIT · EXEMPLE 3

Une fonction async peut return

async function lancerDe() {
  await attendre(1000);
  return Math.ceil(Math.random() * 6);
}

async function jouer() {
  console.log("🎲 Je lance le dé...");
  const resultat = await lancerDe();
  console.log("Tu as fait :", resultat);
}

jouer();

Une fonction async renvoie un ticket → on met await devant pour avoir la valeur.

02 · ASYNC / AWAIT · EXEMPLE 4

Ça peut rater : try / catch

async function entrer(age) {
  try {
    await attendre(500);
    if (age < 18) throw new Error("Trop jeune !");
    console.log("✅ Bienvenue,", age, "ans");
  } catch (erreur) {
    console.log("❌", erreur.message);
  }
}

entrer(25);
entrer(15);

try = « essaie ». Si ça casse, on saute dans catch au lieu de faire planter la page.

02 · ASYNC / AWAIT

Les 3 pièges classiques

Oublier await

Promise {<pending>}

→ ajoute await devant l'appel.

Oublier async

SyntaxError: await is only valid in async functions

→ ajoute async devant function.

Pas de try/catch

Uncaught (in promise) AxiosError

→ entoure l'appel d'un try { } catch { }.

03 · AXIOS

Axios : le facteur de ton JavaScript 📮

1. On l'ajoute dans le HTML, avant notre script :

<script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>
<script>
  // notre code ici
</script>

2. On range l'adresse de l'API dans une constante :

const API = "https://jsonplaceholder.typicode.com";

Pourquoi Axios ? Une ligne par requête · le JSON est converti tout seul · les erreurs 404/500 vont dans catch.

03 · AXIOS · GET

axios.get : lire

async function lireTache() {
  const reponse = await axios.get(`${API}/todos/1`);

  console.log(reponse.status);     // 200
  console.log(reponse.data.title);
  console.log(reponse.data);
}

lireTache();

Les données sont toujours dans reponse.data.

03 · AXIOS

Ce que renvoie Axios

reponse = {

data: { id: 1, title: "..." }, ← 99 % du temps, c'est ça qu'on veut

status: 200, ← le code de réponse

headers, config, request… ← on ignore

}

200 OK 201 Créé 404 Introuvable 500 Erreur serveur

03 · AXIOS · GET

Une liste + des filtres (params)

async function mesTaches() {
  const reponse = await axios.get(`${API}/todos`, {
    params: { userId: 1 }   // → /todos?userId=1
  });
  const taches = reponse.data;

  console.log(taches.length, "tâches");
  const finies = taches.filter((t) => t.completed);
  console.log(finies.length, "terminées");
}

mesTaches();

C'est un tableau d'objets → filter, map, find du Jour 2 !

03 · AXIOS · GET

Afficher dans la page

let taches = [];   // notre copie locale

async function charger() {
  liste.innerHTML = "⏳ Chargement...";
  const reponse = await axios.get(`${API}/todos`, { params: { userId: 1 } });
  taches = reponse.data;
  afficher();
}

function afficher() {
  liste.innerHTML = taches.map((t) => `<li>${t.title}</li>`).join("");
}

Toujours le même schéma : charger les données → les ranger dans taches → afficher().

03 · AXIOS · POST

axios.post : créer

async function creer() {
  const nouvelle = {
    title: "Réviser async/await",
    completed: false,
    userId: 1
  };
  const reponse = await axios.post(`${API}/todos`, nouvelle);

  console.log(reponse.status); // 201 = créé
  console.log(reponse.data);   // + un id
}

creer();

2e argument = l'objet à envoyer. Le serveur répond avec l'objet + son id.

03 · AXIOS · PUT

axios.put : modifier

async function terminer() {
  const tache = { id: 1, userId: 1, title: "Faire le TP", completed: false };

  const modifiee = { ...tache, completed: true };
  const reponse = await axios.put(`${API}/todos/1`, modifiee);

  console.log(reponse.status); // 200
  console.log(reponse.data);
}

terminer();

L'id va dans l'adresse. PUT envoie l'objet complet → le ...spread du Jour 2 est parfait.

03 · AXIOS · DELETE

axios.delete : supprimer

let taches = [{ id: 1 }, { id: 2 }, { id: 3 }];

async function supprimer(id) {
  const reponse = await axios.delete(`${API}/todos/${id}`);
  console.log(reponse.status); // 200

  taches = taches.filter((t) => t.id !== id);
  console.log("Il reste", taches.length, "tâches");
}

supprimer(2);

Pas d'objet à envoyer : juste l'id dans l'adresse. Puis on retire la tâche de notre tableau.

03 · AXIOS

Quand le serveur dit non

async function lireTache(id) {
  try {
    const reponse = await axios.get(`${API}/todos/${id}`);
    console.log("✅", reponse.data.title);
  } catch (erreur) {
    console.log("❌ Erreur", erreur.response?.status);
  }
}

lireTache(3);
lireTache(9999);

Avec Axios, une 404 ou une 500 part directement dans catch. Pas d'Internet ? Aussi.
